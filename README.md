# mrashidi.me

A modern personal portfolio showcasing my work as a Software Engineer. Built with Next.js 16 (App Router), React 19, TypeScript (strict), and Tailwind CSS v4.

> **Note**: This is my personal website and is not intended to be used as a template. The code is shared for transparency and demonstration of my work, but all rights are reserved.

## 🚀 Features

- **Interactive Terminal**: Custom-built terminal with command history and real-time execution
- **GitHub Integration**: Real-time repository display and contribution graph
- **Project Filtering**: Regex search with dynamic technology categorization
- **Blog Integration**: Medium RSS feed with intelligent preloading
- **Email System**: Resend from the API Worker, React Email templates, reCAPTCHA and rate limits
- **Resume Request**: The CV PDF is emailed as a 24-hour signed link to a private Vercel Blob
- **PWA Support**: Progressive Web App with offline capabilities
- **SEO Optimized**: Meta tags, sitemap generation, and structured data

## 🛠 Tech Stack

**Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion, React Hook Form, SWR

**Backend**: Hono on Cloudflare Workers, D1, Resend with React Email, Vercel Blob, Sentry, Pino

**Quality & DX**: pnpm workspaces, Turborepo, Biome, Vitest, Playwright, Turbopack (`pnpm dev`)

## 🏗 Architecture

A pnpm + Turborepo monorepo. The site lives in `apps/web` (Next.js on Vercel); feature-based
organization with domain modules, full TypeScript, and server-side isolation.

```
apps/web/src/
├── app/                    # Next.js App Router (thin route files)
├── features/              # Feature slices: about, ask-mr, blog, contact, home, privacy, projects, resume
├── components/            # UI shared by two or more features
├── lib/                   # Shared logic: API middleware, errors, rate limiting
├── config/                # Theme tokens
└── data/                  # Static profile data
```

## 🔧 Quick Start

```bash
git clone https://github.com/mrdevx/mrashidi.me.git
cd mrashidi.me
pnpm install
cp apps/web/.env.example apps/web/.env.local
pnpm dev
```

**Common verification** (run before pushing substantial changes):

- `pnpm gate` — Biome, agent tooling, then typecheck + unit tests in every package (Turborepo)

**Build**:

- **`pnpm build`** — full production path (Turborepo): regenerates static sitemap XML + OG images, then Next build with **PWA** enabled.
- **`pnpm build:fast`** — skips sitemap/OG regeneration (Next still serves **`/sitemap.xml`** from `apps/web/src/app/sitemap.ts`; committed PNGs remain). Fastest realistic compile/smoke locally.
- **`pnpm --filter @mrashidi/web build:ci`** — alias of **`build:fast`** (used by GitHub Actions CI). **Production deploys should still run `pnpm build`** so sitemap and OG images are regenerated.

See [CONTRIBUTING.md](CONTRIBUTING.md) for commit conventions and local checks detail.

## 📧 Email System

The contact form and CV requests are emailed by the API Worker (`apps/api/src/modules/mail/`)
through Resend, with React Email templates rendered in the Worker. The web routes keep the rate
limits and reCAPTCHA and call the private `/v1/mail/*` routes
([DR-0015](docs/decisions/0015-email-from-api-via-resend.md)).
